# Maak

منصة لاكتشاف وحجز خدمات منزلية موثوقة.

## المنتج

Maak تربط العملاء بمقدّمي الخدمات، وتدعم الحسابات والحجوزات والمحادثات وإدارة مقدّمي الخدمات ولوحة تحكم الإدارة.

## التقنية

- React + Vite + TypeScript
- Supabase للمصادقة وقاعدة البيانات والتخزين
- Cloudflare Worker للـAPI
- GitHub Pages للواجهة المنشورة
- PWA وتجربة متجاوبة للهاتف والحاسوب

## اللغات

العربية الفصحى مع RTL، والفرنسية المهنية مع LTR.
